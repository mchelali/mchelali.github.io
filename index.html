Research directions

Research

CNRS · ANR High Vision · since 2025

Visual heritage and document analysis

Automatic extraction of visual metadata (text, stamps, handwritten notes) from historical photographs, to help archivists and humanities researchers explore large collections. Release of the FORBIN dataset and detection of stamps to study how photographs circulated.

LIPADE · ANR TIMES · 2018–2022

Spatio-temporal representations

Features for 2D+t image sequences: a temporal stability measure based on run-length encoding, and Deep-STaR, planar representations that let 2D CNNs learn spatio-temporal patterns. Applied to satellite image time series and violence detection in videos.

Jellysmack R&D · 2022–2024

Multimodal video understanding

Automatic summarization of long videos into short formats for social networks: speech transcription and text clustering, domain adaptation from public benchmarks, and image captioning and tagging with CLIP and BLIP.

Projects

SA-DETR

A self-attention based object detection model for historical photographs, designed to handle complex visual patterns and diverse object scales.

Explore | Hugging Face

FORBIN Dataset

A collection of 62,135 digitized photographs of Victor Forbin, designed for historical image analysis and archival metadata research.

Explore | Hugging Face

Image Colorization

Photographic colorization service using modern machine learning models based on neural networks. The project was developed during the DataScientest MLOps curriculum.

GitHub repository

Temporal Stability

Spatio-temporal hand-crafted feature extraction for satellite image time series. The proposed method measures stability using a compression algorithm named Run Length Encoding.
